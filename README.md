# BlacBoy's 3D Portfolio

My ArtStation Repo — a personal collection of 3D asset work, references, materials, and portfolio pieces created for visual exploration and presentation.

## Overview

This repository serves as a portfolio archive for selected 3D projects and asset libraries. It is organized by character and environment studies, each containing source material, reference imagery, and supporting textures or Blender-related metadata.

The work here is intended to showcase modeling, texturing, and asset organization in a reusable portfolio format.

## Featured Projects

### Submersible
A themed underwater-inspired project containing source files and reference assets for a 3D model or environment study.

- `Submersible/Source/`
- `Submersible/Refs/`

### Toad
A separate 3D asset project with materials, references, and source assets for a creature or character-focused study.

- `Toad/Source/`
- `Toad/References/`
- `Toad/Materials & Textures/`

### Legacy Asset Library
The `_v1` folder includes earlier exported asset metadata and index files, preserving a historical snapshot of the asset library.
