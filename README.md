# BlacBoy

### 3D Artist / Portfolio

Dedicated to creating stylized 3D work, hard-surface and creature studies, and art-focused asset libraries. This repository is a curated collection of personal projects, references, materials, and production files developed as part of an evolving portfolio.

## About

I am a 3D artist exploring visual storytelling through box-modelling, texturing, and asset development. This collection reflects my ongoing practice across concept-driven models, material exploration, and portfolio presentation.

The repo acts as both a creative archive and a visual résumé of selected work, showcasing project progression and the thinking behind each design.

---

## Portfolio Highlights

### Submersible
An underwater-inspired project focused on atmospheric design and form exploration. The work includes source files and reference material assembled for a polished presentation.

- Source assets and modeling references
- Visual direction and concept-driven development
- Organized for clean portfolio presentation

### Toad
A character and creature-focused study with material, texture, and reference content. This project explores form language and visual identity through a more grounded and expressive approach.

- Character/creature development assets
- References and material studies
- Texture and presentation-ready asset organization

### Legacy Asset Library
A historical collection of earlier asset metadata and index files, preserving a record of previous work and library organization.

- archived project index
- asset metadata
- previous portfolio structure
